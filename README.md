## 🏛️ Executive Summary

I engineer fault-tolerant, mission-critical systems designed to operate reliably under extreme conditions: intermittent connectivity, high-concurrency peak loads, and heterogeneous infrastructure.

* **Systems & Backend Architecture**: Event-driven microservices, CQRS, transactional outboxes, and distributed consensus for high-load systems.
* **Digital Public Infrastructure (DPI) & Fintech**: Financial reconciliation engines, Sahel mobile money gateways (Amana, NITA, Flooz, Airtel Money), and verifiable identity layers.
* **Edge & Computer Vision**: Hardware-accelerated real-time edge processing (BarcodeDetector API <30ms latency) without server round-trips.
* **Offline-First Resilience**: Vector tile map streaming, differential state synchronizations, and local SQLite/Hive persistence for unreliable networks.

## ⚡ Flagship Architectures & Engineering (2026)

### 🏥 [Hayat Platform](https://github.com/karaag2) — Distributed Healthcare DPI & Telemedicine Ecosystem
> **Architecture**: Distributed Event-Driven Microservices · CQRS · Moleculer.js · GridFS Multipart Stream · FinTech Integrations
* **Resilient Microservices**: Built on Moleculer.js with broker-level service discovery, circuit breakers, and distributed tracing.
* **High-Throughput Medical File Storage**: Engineered chunked multipart streaming on MongoDB GridFS for large radiological imaging and electronic health records.
* **Sahelian FinTech Payment Engine**: Unified payment routing and automated financial reconciliation layer integrating NITA, Amana Transfert, and mobile money operators with atomic ledger rollback guarantees.

### 🎟️ [TicketManager](https://github.com/karaag2/TicketManagerTomodachiCrew) (Tomodachi Crew) — Ultra-Low Latency Access & Edge Computer Vision
> **Architecture**: Edge WebAssembly/BarcodeDetector API · NestJS · Neon PostgreSQL (Serverless) · High-Concurrency Ingress
* **Sub-30ms Edge Scans**: Implemented client-side hardware-accelerated computer vision scanning via the Web BarcodeDetector API, eradicating cloud latency at entry gates.
* **High-Concurrency Anti-Fraud Engine**: Designed optimistic concurrency control and distributed ticket invalidation preventing double-entry replay attacks across parallel turnstiles during peak event spikes.

### 🚌 [TheBusApp](https://github.com/karaag2/TheBusApp) — Inclusive Offline-First Urban Mobility Engine
> **Architecture**: Flutter · Embedded Offline MBTiles Vector Engine · Resilient Sync Broker
* **Zero-Bandwidth Navigation**: Bundled custom local vector tile extractors and offline route calculators, allowing commuters to navigate transit grids without active cellular networks.
* **Differential State Sync**: Background synchronization queue resolving optimistic ticket purchases and GPS fleet telemetry once network connectivity restores.

### 🏢 [Hypertech Plus SaaS v3](https://github.com/karaag2) — Multi-Tenant Enterprise Operations & Billing ERP
> **Architecture**: Multi-Tenant Isolation · RBAC/ABAC Security · High-Volume Financial Stream
* **Architectural Migration**: Re-architected legacy infrastructure into a zero-trust multi-tenant SaaS hosting 20+ enterprises and processing millions of FCFA in monthly transaction flows.
* **Compliance & Auditing**: Immutable audit trails, automated ledger balancing, and end-to-end data segregation.

### 🏺 [Artisaline Platform](https://github.com/karaag2/artisaline-backend) — Cultural Commerce Engine for Sahelian Craftsmanship
> **Architecture**: Express · Prisma ORM · PostgreSQL · High-Performance Catalog
* **Localized E-Commerce**: High-conversion responsive storefront backed by an optimized REST API powering artisans across West Africa, pairing rich regional media catalogues with efficient database query plans.
